# AI use

OpenAI ChatGPT and Codex assisted with research, software engineering, test design, interface refinement, and drafting documentation and submission text. NASA data are cited separately. The Python pipeline deterministically computes production results from recorded NASA POWER responses. Synthetic series appear in automated tests only. The app has no runtime language-model calls.

The planned demo uses an actual screen recording of the application and spoken narration. Update this disclosure if the team adds generated media or uses additional AI tools. The project is a NASA Space Apps Challenge participant entry.
